# How a phone call crosses the world

An interactive isometric model of one phone call from Istanbul to New York: voice → microphone and ADC → codec → radio → core network → fibre → transatlantic cable → New York's network → DAC and speaker, in both directions at once.

- Dark: https://onurfeyyaz.github.io/phone-call-anatomy/
- Light: https://onurfeyyaz.github.io/phone-call-anatomy/light.html

Timings are typical values from a model of each stage, not a measurement of a real call.
